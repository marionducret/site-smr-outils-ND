Analyse d'activité par GME

Visualisez les évolutions d'effectifs par CM, GN, GME et type de réadaptation.

Ouvrir l'outil →

Fichiers d'entrée

  • Les fichiers appli_05.zip d'un établissement, pour en extraire les tableaux t1d2gmehp.html et t1d2gmehc.html.
  • Vous pouvez glisser plusieurs fichiers / plusieurs périodes d'un coup pour comparer les années.

Étapes

  1. Ouvrez la page Analyse GME.
  2. Glissez vos fichiers dans la zone prévue (ou cliquez pour parcourir).
  3. Explorez les évolutions de journées par GN et par type de réadaptation ; les graphiques se mettent à jour automatiquement.

Pièges à éviter

  • Ne glissez pas les pièces jointes directement depuis un e-mail : enregistrez-les d'abord sur le disque, puis glissez-les depuis l'Explorateur / le Finder.
🔒 Les fichiers sont analysés dans votre navigateur : aucune donnée n'est envoyée sur internet.
