Analyse des dépendances live

Générez un fichier d'analyse avec filtres de scores de dépendance modifiables.

Ouvrir l'outil →

Fichiers d'entrée

  • L'Excel produit par le convertisseur RHS.

Ce que vous obtenez

  • Un fichier …_dependance_.xlsx autonome : un bloc de filtres modifiables (type de dépendance, scores) et un tableau par séjour qui se recalcule tout seul dans Excel.

Étapes dans Excel

  1. Choisissez physique / cognitive / les deux dans le menu déroulant B7.
  2. Écrivez les scores recherchés en B8/B9 (ex. 7,8).
  3. Filtrez la colonne « Afficher ? » sur OUI.
💡 Seuls les séjours en hospitalisation complète (Type Hospit. = 1) avec NL = A sont analysés.
