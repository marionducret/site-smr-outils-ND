Analyse live dépendances

À partir de l'Excel RHS (sortie du convertisseur RHS → ENC), génère un fichier d'analyse avec filtres modifiables directement dans Excel : scores de dépendance physique / cognitive par séjour (HC, NL = A).

🔒 Traitement 100 % local — vos fichiers ne quittent jamais cet ordinateur

Glissez votre fichier Excel RHS (.xlsx) ici

ou cliquez pour le sélectionner — l'onglet « RHS » est détecté automatiquement

Aide & mode d'emploi
  • Entrée : l'Excel produit par le convertisseur RHS → ENC (ou tout Excel avec un onglet « RHS » contenant les colonnes N° Séjour, Type Hospit., NL, N° Sem. + Année et les scores de dépendance).
  • Sortie : un fichier …_dependance_.xlsx avec un bloc de filtres modifiables (type de dépendance, scores recherchés) : le tableau se recalcule tout seul dans Excel, sans relancer l'outil.
  • Dans Excel : choisissez physique / cognitive / les deux en B7, écrivez les scores en B8/B9 (ex. 7,8), puis filtrez la colonne « Afficher ? » sur OUI.
  • Seuls les séjours en hospitalisation complète (Type Hospit. = 1) avec NL = A sont analysés.
