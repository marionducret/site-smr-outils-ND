Analyse des dépendances (version statique)

Isolez les séjours correspondant aux scores de dépendance physique et/ou cognitive définis.

Ouvrir l'outil →

Fichiers d'entrée

  • L'Excel produit par le convertisseur RHS.

Étapes

  1. Glissez le fichier, choisissez le type de dépendance et le(s) score(s) recherché(s) (ex. 7,8).
  2. Cliquez sur « Filtrer » : l'Excel des séjours retenus arrive dans vos Téléchargements, avec le combo de filtres dans son nom.
  3. Pour tester un autre combo, changez les valeurs et relancez.
💡 Pour explorer plusieurs combos sans relancer l'outil, préférez l'analyse dépendances live : les filtres se modifient directement dans Excel.
