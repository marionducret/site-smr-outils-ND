Tutoriels

Mode d'emploi de chaque outil : quoi préparer en entrée, ce que vous obtenez en sortie, et les pièges à éviter.

📊 Rapport mensuel — mode d'emploi

À quoi ça sert

  • Générer le rapport d'évolution mensuelle des séjours et de la valorisation PMSI d'un établissement SMR, prêt à diffuser.

Étapes

  1. Ouvrez l'onglet Rapport mensuel (l'application s'ouvre dans le navigateur).
  2. Sélectionnez l'établissement et la période, puis laissez-vous guider par l'application : elle indique à chaque étape les fichiers à charger.
  3. Téléchargez le rapport généré à la fin.
⏱ Au premier accès, l'application peut mettre ~30 secondes à « se réveiller » (hébergement gratuit). C'est normal — patientez puis rechargez si besoin.
📈 Analyse GME — mode d'emploi

Fichiers d'entrée

  • Les fichiers appli_05.zip d'un établisement pour extraire les tableaux t1d2gmehp.html et t1d2gmehc.html.
  • Vous pouvez glisser plusieurs fichiers / plusieurs périodes d'un coup pour comparer les années.

Étapes

  1. Ouvrez l'onglet Analyse GME.
  2. Glissez vos fichiers dans la zone prévue (ou cliquez pour parcourir).
  3. Explorez les évolutions de journées par GN et par type de réadaptation ; les graphiques se mettent à jour automatiquement.

Pièges à éviter

  • Ne glissez pas les pièces jointes directement depuis un e-mail : enregistrez-les d'abord sur le disque, puis glissez-les depuis l'Explorateur / le Finder.
🔒 Les fichiers sont analysés dans votre navigateur : aucune donnée n'est envoyée sur internet.
🔄 Convertisseur RHS — mode d'emploi

Fichiers d'entrée

  • Le fichier RHS au format texte (.txt).

Ce que vous obtenez

  • Un classeur Excel NomDuFichier_ENC.xlsx avec trois onglets : RHS (une ligne par RHS, colonnes DAS / CSARR / CCAM adaptées au contenu), CSARR_ENC (un acte CSARR ou CSAR par ligne, libellés métier et SAMT renseignés) et CCAM_ENC (un acte CCAM par ligne).

Étapes

  1. Ouvrez l'onglet Convertisseur RHS.
  2. Glissez votre fichier .txt (plusieurs fichiers possibles), puis cliquez sur Convertir en Excel.
  3. Le fichier Excel arrive dans vos Téléchargements.

Pièges à éviter

  • Le premier lancement charge le moteur de calcul (~15 Mo) : comptez 20 à 40 secondes. Les fois suivantes sont quasi instantanées.
  • Si le fichier n'est ni M1C ni M1D, l'outil affiche une erreur avec le numéro de ligne concerné.
🔒 La conversion s'exécute entièrement dans votre navigateur : aucune donnée patient ne quitte votre ordinateur.
💶 Anomalies transmissions/recettes — mode d'emploi

Fichiers d'entrée

  • Les CSV VisualValoSejours d'un même établissement et d'une même année.
  • Glissez toutes les transmissions à comparer d'un coup (M1 à Mn).

Ce que vous obtenez

  • Un Excel avec un bloc de colonnes par transmission : jours valorisés, montants BR et AM agrégés par séjour-semaine, écart AM vs transmission précédente, séjours absents grisés, ligne TOTAL et nombre de jours valorisés supplémentaires.

Pièges à éviter

  • Ne mélangez pas plusieurs établissements ou plusieurs années : l'outil refuse et vous l'indique.
  • Gardez les noms de fichiers d'origine — le mois est lu dans le nom du fichier.
🔒 Les CSV sont traités dans votre navigateur : aucune donnée n'est envoyée sur internet.
🧩  Analyse dépendances live — mode d'emploi

Fichiers d'entrée

  • L'Excel produit par le convertisseur RHS

Ce que vous obtenez

  • Un fichier …_dependance_.xlsx autonome : un bloc de filtres modifiables (type de dépendance, scores) et un tableau par séjour qui se recalcule tout seul dans Excel.

Étapes dans Excel

  1. Choisissez physique / cognitive / les deux dans le menu déroulant B7.
  2. Écrivez les scores recherchés en B8/B9 (ex. 7,8).
  3. Filtrez la colonne « Afficher ? » sur OUI.
💡 Seuls les séjours en hospitalisation complète (Type Hospit. = 1) avec NL = A sont analysés.
🔍 Analyse dépendances statique — mode d'emploi

Fichiers d'entrée

  • L'Excel produit par le convertisseur RHS.

Étapes

  1. Glissez le fichier, choisissez le type de dépendance et le(s) score(s) recherché(s) (ex. 7,8).
  2. Cliquez sur « Filtrer » : l'Excel des séjours retenus arrive dans vos Téléchargements, avec le combo de filtres dans son nom.
  3. Pour tester un autre combo, changez les valeurs et relancez.
💡 Pour explorer plusieurs combos sans relancer l'outil, préférez l'Analyse dépendances live : les filtres se modifient directement dans Excel.
📚 CSAR Thesaurus — mode d'emploi

Fichiers d'entrée

  • Le ZIP "appli05" contenant le tableau …ano-rha-sha.t1d2csarr.html de l'établissement.
  • Le nom de l'établissement est détecté automatiquement ; vous pouvez le saisir manuellement pour l'imposer.

Ce que vous obtenez

  • L'Excel global Etablissement_CSAR_2026.xlsx : actes CSARR 2025 transcodés en CSAR 2026, effectifs, définitions, modulateurs, intervenants attendus.
  • Un ZIP avec un fichier Excel par intervenant (actes réalisés, actes autorisés CSAR 2026, référence modulateurs/modalités).

Pièges à éviter

  • Les référentiels CSAR 2026 sont intégrés dans le site : en cas de nouvelle version ATIH, ils doivent être remplacés dans le site (demandez le changement à Marion).
  • Premier lancement : ~30–60 s de chargement du moteur, puis quasi instantané.
🔒 Le ZIP est traité dans votre navigateur : aucune donnée n'est envoyée sur internet.
