CSAR Thesaurus

À partir du tableau OVALIDE t1d2csarr (.zip) d'un établissement, génère le fichier Excel CSAR 2026 global (transcodage CSARR → CSAR, modulateurs, intervenants attendus) et le ZIP des fichiers par intervenant.

🔒 Traitement 100 % local — vos fichiers ne quittent jamais cet ordinateur

ou cliquez pour le sélectionner — fichier .zip contenant …ano-rha-sha.t1d2csarr.html

Aide & mode d'emploi
  • Entrée : le ZIP OVALIDE contenant le tableau …ano-rha-sha.t1d2csarr.html de l'établissement. Le nom de l'établissement est détecté automatiquement ; vous pouvez le saisir manuellement pour l'imposer.
  • Sorties : l'Excel global Etablissement_CSAR_2026.xlsx (actes CSARR 2025 → CSAR 2026, effectifs, modulateurs, intervenants attendus) et un ZIP avec un fichier Excel par intervenant (3 onglets : actes réalisés, actes autorisés CSAR 2026, référence modulateurs/modalités).
  • Les référentiels CSAR 2026 (attendus, descriptions, fichier ATIH, noms intervenants) sont embarqués dans le site : rien à fournir. En cas de mise à jour des référentiels, ils sont à remplacer dans le dossier assets/csar2026/ du site.
  • Le premier lancement charge le moteur de calcul (~25 Mo avec le lecteur HTML) : comptez 30–60 s. Ensuite c'est quasi instantané.
