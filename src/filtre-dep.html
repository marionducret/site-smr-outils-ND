Filtre dépendances

Extrait de l'Excel RHS les séjours dont les scores de dépendance physique et/ou cognitive correspondent aux valeurs recherchées (HC, NL = A), avec moyennes par séjour.

🔒 Traitement 100 % local — vos fichiers ne quittent jamais cet ordinateur

Glissez votre fichier Excel RHS (.xlsx) ici

ou cliquez pour le sélectionner — puis choisissez le type de dépendance et les scores ci-dessous

Aide & mode d'emploi
  • Entrée : l'Excel produit par le convertisseur RHS → ENC (onglet « RHS » détecté automatiquement).
  • Paramètres : type de dépendance (physique, cognitive ou les deux) et score(s) recherché(s), séparés par des virgules (ex. 7,8).
  • Sortie : un Excel …_dep_phys7-8….xlsx listant les séjours retenus : nombre de semaines total, semaines correspondant aux scores, scores moyens — avec le rappel des filtres utilisés.
  • Pour tester plusieurs combinaisons de scores, relancez simplement avec d'autres valeurs : chaque export porte le combo dans son nom. Pour des filtres modifiables directement dans Excel, utilisez plutôt l'Analyse live dépendances.
